# 📦 Warehouse Management System

A full-featured Warehouse Management System built with PHP and MySQL to streamline inventory operations, track stock movements, manage users, and keep reorder levels under control with ease.

---

## ✨ Features

- 📦 **Item Management**: Create, edit, and organize SKUs with category, location, unit, and reorder level.
- 🔄 **Stock Movements**: Record IN / OUT transactions with reference notes and automatic quantity updates.
- ⚠️ **Low Stock Alerts**: Dashboard highlights items below threshold so you can restock before stockouts.
- 📊 **Movement Reports**: Filter stock history by date range, movement type, and item.
- 🔐 **Authentication**: Secure login with session-based auth and role-based access control (admin / user).
- 👥 **User Management**: Admins can manage accounts and reset passwords.
- 👤 **Profile**: Users can update their own password from the profile page.
- 🔍 **Search & Browse**: Quickly find items by code or name and view detailed item pages.
